# Study 1 - Kids (draft, placeholder stimuli)
Double-click `index.html` to run (needs internet for jsPsych CDN).
- `js/stimuli.js` : all items (placeholders) + question wording. Edit here.
- `js/experiment.js` : trial logic, randomization, counterbalancing, CSV save.
- `assets/animals/*.svg` : placeholder animals. Replace with final art (same names, or edit paths in stimuli.js).
URL options: `index.html?pid=3` (participant number), `?audio=1` (read aloud).
Data: a CSV of the 20 test trials downloads automatically at the end.
